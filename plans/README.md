## Deferred direction options

These are product choices, not defects, and are not part of this nine-plan batch:

- **`OutputStream` and stdout export (S–M)**: enables compressed pipes, HTTP responses, and object-store uploads without intermediate files; requires explicit stream-ownership and stdout logging rules.
- **Positional query parameters (M)**: additive overloads can bind runtime filters through the existing `PreparedStatement` path without introducing a query builder; requires JDBC null-typing and overload-design decisions.
- **Split output by rows or bytes (M–L)**: requires naming templates, per-part CSV header rules, byte-count semantics, and partial-part failure behavior.
- **Optional Parquet export spike (L)**: investigate a separate module so heavyweight dependencies stay out of core; schema mapping and dependency footprint remain unknowns.

## Findings considered and rejected

- **JDBC URL “injection”**: the caller controls its own connection configuration; no separate trust boundary was demonstrated. The concrete null-host defect is plan 005.
- **Playground CTE bypass and clickjacking as security findings**: the read-only database user, Host/Origin checks, and fictional sample data left no demonstrated production security impact.
- **Forced `0600` output permissions**: overriding normal umask behavior would surprise CLI users and differs from standard export-tool behavior.
- **CSV spreadsheet-formula escaping**: mutates legitimate exported data and breaks programmatic pipelines.
- **Broad `SQLClient` removal**: the public interface and public client constructors make this a compatibility-sensitive abstraction project without enough standalone leverage.
- **Size-only Playground decomposition**: file size alone is not a defect. Removing only its metadata proxy would also be incomplete because timeout cancellation still tracks JDBC statements.
- **Interactive stdin blocking**: expected behavior for a CLI that explicitly reads SQL from standard input.
- **MySQL protobuf exclusion and JSON normalization rewrite**: unmeasured benefit did not justify dependency or hot-path compatibility risk.
- **Additional style tooling**: the repository deliberately uses focused doclint and existing conventions; a new style framework was not high-leverage enough to plan.
